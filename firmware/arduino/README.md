# Firmware Arduino

Organização inicial de firmware para Arduino UNO e Arduino Mega. `hall-sensor/` é reservado a leituras de sensor Hall analógico, incluindo o 49E do experimento inicial; `optical-sensors/` é reservado a sensores ópticos de presença e velocidade.

Possibilidades futuras incluem medir corrente, tensão e temperatura, acionar bobinas e transmitir dados ao gêmeo digital. Placa, pinos, alimentação, taxas de amostragem, calibração e protocolo de comunicação devem ser documentados em cada implementação. Nenhuma dessas funções está definida ou implementada aqui.
