# Hardware

`schematics/` armazenará esquemas elétricos; `cad/`, modelos da pista e componentes (incluindo arquivos do Fusion 360); `components/`, informações e referências dos componentes. Identifique revisão, unidades, fabricante e condições de uso de cada artefato. Confirme requisitos térmicos e elétricos antes de fabricar ou energizar conjuntos.
